# BilimBaga — Корпоративная платформа для тестирования и оценки знаний

**BilimBaga** — это корпоративная платформа для проведения экзаменов и оценки знаний сотрудников. Она создана для организаций, которым необходимо структурированное, измеримое тестирование персонала — по подразделениям, на нескольких языках, с полной прозрачностью и отчётностью.

---

## Возможности платформы

### Прохождение экзаменов сотрудниками
Сотрудники получают доступ к личному порталу, где видят назначенные им экзамены, проходят их в удобном интерфейсе с защитой от отвлечений и сразу получают результаты. Платформа поддерживает пять типов вопросов: одиночный выбор, множественный выбор, «верно/неверно», шкала Ликерта и краткий текстовый ответ. Предусмотрены встроенный таймер, пометка вопросов для повторного просмотра и обнаружение переключения вкладок. После сдачи экзамена сотрудник видит свой балл, статус «сдал/не сдал» и может скачать сертификат при успешном прохождении.

### Создание экзаменов
Администраторы и экзаменаторы составляют экзамены через пошаговый мастер из 4 шагов: настройка базовых параметров (лимит времени, проходной балл, перемешивание вопросов, защита от списывания, выдача сертификата) → определение правил подбора вопросов (ручной выбор или случайная выборка по категориям и тегам) → назначение подразделениям или конкретным сотрудникам → проверка и публикация.

### Банк вопросов
Централизованный версионируемый банк вопросов с полной поддержкой многоязычного контента (текст вопроса и варианты ответов на каждом языке). Вопросы можно создавать вручную, импортировать из CSV или генерировать с помощью ИИ по заданным параметрам (тема, сложность, количество). Банк поддерживает иерархию категорий, теги, уровни сложности и полный цикл редактирования и согласования (черновик → проверка → активен → архив).

### Аналитика и отчётность
Администраторы видят живую панель с ключевыми показателями: численность сотрудников, активные экзамены, средний балл, процент завершения, список просроченных. Аналитика по каждому экзамену включает распределение баллов, процент сдачи и статистику сложности по каждому вопросу. Для экзаменов по ценностям и лояльности доступны нарративные аналитические выводы, сгенерированные ИИ. В карточке сотрудника отображается полная история тестирования и прогресс по трекам.

### Ручная проверка
Текстовые ответы направляются в очередь ручной проверки. Экзаменатор выставляет оценку по каждому ответу (0–100) с письменным комментарием, после чего итоговый балл сессии пересчитывается автоматически.

### Управление пользователями и подразделениями
Иерархическая структура подразделений с ролевой моделью доступа на основе пяти ролей: **Супер-администратор**, **Администратор подразделения**, **HR-администратор**, **Экзаменатор** и **Сотрудник**. Пользователей можно создавать по одному или импортировать из CSV. Поддерживаются временные пароли с принудительной сменой при первом входе и деактивация аккаунтов без потери данных.

### Соответствие требованиям и аудит
Неизменяемый журнал аудита фиксирует все значимые действия: входы в систему, изменения пользователей, публикации экзаменов, выставление оценок. Доступен полный экспорт в CSV для нужд комплаенс-проверки.

### Брендирование
Каждое развёртывание полностью брендируется: название приложения, логотип, основной и акцентный цвета, поддерживаемые языки — всё настраивается на странице параметров администратора с предварительным просмотром в реальном времени.

## Ключевые возможности

| Возможность | Детали |
|---|---|
| Типы вопросов | Одиночный выбор, множественный выбор, верно/неверно, шкала Ликерта, краткий текст |
| Языки | Полная многоязычность — любое количество локалей для каждого вопроса |
| ИИ-функции | Генерация вопросов, аналитические выводы по экзаменам, нарратив ценностей |
| Управление доступом | 5 ролей, разграничение прав по подразделениям |
| Защита от списывания | Обнаружение переключения вкладок, настраивается для каждого экзамена |
| Сертификаты | Автоматическая выдача при сдаче, QR-верификация |
| Массовые операции | Импорт пользователей и вопросов из CSV |
| Журнал аудита | Неизменяемый лог, фильтрация, экспорт в CSV |
| Брендирование | Полный white-label для каждого развёртывания |

---

*Технологический стек: Go + React + PostgreSQL. Развёртывание через Docker Compose. Спроектирована для single-tenant корпоративного использования с готовой архитектурой для multi-tenant.*
